# Play 데이터 보안 양식 (초안 2026-10-11)

Play Console → 앱 콘텐츠 → 데이터 보안. **웹뷰로 불러오는 kissinskin.net 이 수집하는 것도 앱 수집으로 신고**한다.
근거 = `src/pages/privacy.tsx`(10/11 개정) + 실제 코드. 방침과 어긋나면 심사 반려 사유가 된다.

## 공통 질문
| 질문 | 답 | 근거 |
|---|---|---|
| 필수 데이터 유형을 수집·공유하나요? | 예 | 아래 표 |
| 전송 중 암호화되나요? | 예 | 전부 HTTPS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예 | 마이페이지 회원 탈퇴(`functions/api/delete-account.ts`, cascade) + support@kissinskin.net |
| 계정 삭제 URL | ⏭️ **로그인 없이 열리는 안내 페이지 필요** (아래 할 일) | Play 필수 항목 |

※ "공유" = 제3자에게 넘겨 그쪽 목적으로 쓰이는 것. OpenAI·Supabase·Resend·Cloudflare 처럼 **우리를 대신해 처리하는 서비스 제공업체로의 전송은 공유가 아님**(Play 정의).

## 수집 항목
| 유형 (Play 분류) | 수집 | 공유 | 필수/선택 | 목적 | 비고 |
|---|---|---|---|---|---|
| 개인 정보 › 이메일 주소 | 예 | 아니요 | 선택 | 계정 관리, 개발자 커뮤니케이션 | 로그인·구독 시에만 (Supabase, Resend) |
| 개인 정보 › 사용자 ID | 예 | 아니요 | 선택 | 계정 관리, 앱 기능 | Supabase 사용자 id |
| 사진 및 동영상 › 사진 | 예 | 아니요 | 선택 | 앱 기능 | AI 메이크업용 셀카. **임시 처리**(저장 안 함) 체크. 단 사용자가 저장·공유한 *결과 이미지*는 보관 → "임시 처리"는 업로드 원본 기준. 얼굴형 측정은 기기 내 처리라 수집 아님 |
| 금융 정보 › 구매 기록 | 예 | 아니요 | 선택 | 앱 기능 | 크레딧 충전·차감 내역(`user_credits`). 결제 자체는 Polar(외부 브라우저) |
| 앱 활동 › 앱 상호작용 | 예 | 아니요 | 선택 | 분석 | GA4·Clarity |
| 앱 활동 › 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 선택 | 앱 기능 | 저장한 진단 결과·룩(내 뷰티 기록) |
| 기기 또는 기타 ID | 예 | 아니요 | 선택 | 앱 기능(푸시), 분석 | Expo 푸시 토큰(KV `PUSH_TOKENS`), GA4 클라이언트 ID |
| 위치 › 대략적인 위치 | 예 | 아니요 | 선택 | 분석 | GA4 가 IP 로 국가·도시 추정. 보수적으로 신고 |

수집 안 함: 정밀 위치, 연락처, 이름·주소·전화(결제 시 Polar 가 직접 받음), 건강, 메시지, 오디오, 파일, 캘린더, 웹 기록, 비정상 종료 로그.
